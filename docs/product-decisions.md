# 产品决策记录

## 已确定

- 用户定位：本人和朋友休闲打牌。
- 使用界面：电脑浏览器优先，兼顾手机操作。
- 联机方式：局域网内访问同一个 Web 服务器。
- 真人人数不足时由电脑牌手补位。
- 电脑牌手目标：普通牌友水平；第一阶段验收线为规则正确、决策基本合理。
- 访问方式：所有玩家统一通过浏览器访问局域网 Web 服务，无需安装软件或运行启动脚本；单机模式也是一名真人访问该服务，与三名电脑牌手游玩。
- 离线能力：启动后完全不依赖互联网，电脑牌手也在本地运行。
- 计分方式：每副牌独立计分，累计南北和东西双方得分；第一版不做多桌比赛排名。
- 叫牌体系：第一版采用简化自然叫牌，具体开叫、应叫和常用约定待明确，并提供游戏内说明。
- 座位：真人自由选择东南西北座位，房主开局时由电脑填满空位，支持 1～4 名真人。
- 掉线：短暂等待后由电脑接管；原玩家重连可取回座位。
- 中途加入：新玩家等下一副牌再替换电脑。
- 第一版辅助功能：合法操作提示、叫牌与出牌记录、结束后查看四家手牌；不提供策略推荐和悔牌。
- 简化自然叫牌：五张高花、1NT 开叫 15～17 点、强 2♣、其余二阶花色弱开叫，支持基础应叫、Stayman 和高花转移叫；不允许自定义体系，提供中文约定表。
- 牌副衔接：随机发牌，按固定的 16 副牌周期轮换发牌人和局况；每副结束显示得分明细，所有真人准备后继续，电脑自动准备。
- 累计分按南北、东西方位记录，中途换人不清零。
- 一个服务器支持多个独立房间；昵称加房间码进入，无需注册；同一浏览器保留重连身份，房间内不允许重复昵称；第一版不支持旁观。
- 联机掉线等待 30 秒后由电脑接管；原玩家重连后，在下一次需要该座位操作前交还控制，已完成的操作不撤回。
- 正常操作不限时；房主可以暂停整桌；单机关闭页面后自动暂停，回来继续。
- 自动保存每次已完成的叫牌和出牌；服务重启后恢复到最后保存的位置，整桌暂停，等待房主确认继续。
- 玩家端交付：局域网 Web 页面，简体中文界面，无需安装。此前的玩家端 Windows 启动脚本方案已被此要求替代。
- 服务端部署：一台 Windows 电脑，游玩期间保持开机；仅服务端需要部署，所有玩家通过浏览器访问。
- 服务端交付：附带运行环境和已构建页面的目录，解压后双击启动，显示局域网地址，管理员无需安装开发工具；数据目录独立保存。
- 容量验证目标：10 桌同时游玩，测试包含电脑决策负载；尚未进行实测。
- 电脑牌手严格遵循信息限制，只使用自己手牌、依法公开的明手及叫牌和出牌记录；允许推测暗牌，禁止读取实际暗牌。电脑共用公开的叫牌约定，不私下交换信息。
- 房主掉线满 30 秒后，将房主权限交给最早加入且仍在线的真人。
- 全部真人离线时立即暂停并保存；有人重连后，由当前房主确认继续。
- 已被电脑接管的座位为原玩家保留；新玩家只能在下一副牌接替未被真人占用的电脑座位。

## 开发范围与验收顺序

1. 实现完整桥牌对局：发牌、叫牌、定约、打牌、结算与下一副牌；非法操作必须被拒绝。
2. 实现入门电脑牌手：自动补位，覆盖叫牌、做庄和防守，遵守信息限制；此阶段不宣称达到普通牌友水平。
3. 实现浏览器房间和 1～4 真人混合对局：自由选座、多房间、准备、记录及结束后查看四家手牌。
4. 实现断线接管、重连、房主转交、暂停、自动保存和服务重启恢复。
5. 完成 Windows 服务端部署与局域网验证：玩家免安装，运行时不依赖互联网，电脑浏览器优先并兼顾手机。
6. 在基础版通过验收后，继续提升电脑叫牌和打牌能力，以普通牌友水平为目标。
