# 采用 Windows 局域网服务统一维护牌局

所有玩家免安装、通过浏览器访问同一局域网服务，且运行时不能依赖互联网，因此采用 Windows 单机部署：React、TypeScript、Vite 构建前端，Node.js、TypeScript、Fastify 提供服务，Socket.IO 同步操作，本地 SQLite 保存状态和记录。服务端统一验证并提交牌局变化，只向每个玩家及电脑牌手提供其有权获知的信息，以满足联机一致性、暗牌隔离和重启恢复要求。

## 取舍

前后端统一 TypeScript，规则和电脑策略分别封装，降低第一阶段集成与部署负担；后续如需 Python 或原生电脑引擎，通过独立接口接入，不要求 Web 服务随之更换语言。相较于让浏览器自行主持对局，本方案需要主机持续运行，但能够统一保存和恢复牌局；相较于外部数据库及云服务，本地 SQLite 降低部署负担并满足离线要求，接受单机容量边界。

## 交付与验证

服务端以附带运行环境的目录交付，解压后双击启动，数据与程序分离；客户端只需浏览器。容量目标为 10 桌同时游玩，需连同电脑决策进行实测；可靠性需覆盖操作去重、按桌顺序执行、事务提交后确认、重连状态同步及服务重启恢复，不能仅依赖 Socket.IO 的连接恢复功能。
