# 03：房主开局、发牌与私有手牌展示

Status: ready-for-agent

Blocked by: 02：通过浏览器创建房间、加入与选座

**交付行为：** 房主启动一副牌，玩家看到副号、局况、行动方和自己有权查看的手牌。

## 验收标准

- [x] 仅房主能开局，支持 1～4 个真人座位，空位标记为电脑座位；本票电脑尚不自动行动，使用四真人验证流程。
- [x] 发出不重复的完整 52 张牌，每家 13 张，初始化副号、发牌人、局况与叫牌行动方。
- [x] 客户端仅收到本人手牌及公开信息，其他座位只显示牌背或张数；等待者、错误响应及重连快照均不能泄露暗牌。
- [x] 发牌与阶段状态持久化，重复开局不重复发牌；以可控发牌测试授权及版本过期行为。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T03 的开局部分、T12、T15。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
