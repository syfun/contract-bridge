## 验收标准

- [x] 实现基础首攻、做庄、依法控制明手及防守，满足第 01 票固定评估牌例；不宣称普通牌友水平。
- [x] 四种真人人数均能从开局完成到结算与下一副，电脑无非法动作、死循环或无法继续的牌局。
- [x] 打牌策略沿用合法可见信息限制，使用暗牌变化测试验证；每个电脑独立接收信息。
- [x] 电脑结果由应用服务按当前轮次、版本与控制权接收，计算不阻塞其他房间；结算后自动准备。
- [x] 运行可复现的批量牌例并记录通过结果，对规则正确和基本合理分别报告。

## 依据与实施约束

- 已确认规则与评估依据：[电脑叫牌约定与基础牌力评估](../decisions/01-computer-conventions.md)，版本 `computer-conventions-v1.0`；实现、中文帮助及验收按对应规则/牌例标识引用。
- [正式规格](../spec.md)。验收覆盖：T03、T13、T14、T17 的过期结果部分。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
