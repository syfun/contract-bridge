# 14：交付 Windows 离线启动包

Status: ready-for-agent

Blocked by: 12：全员离线、房主转交与服务重启恢复；13：中途加入、退出与两副之间换人

**交付行为：** 管理员在 Windows 上解压双击即可启动局域网服务，玩家离线使用浏览器完成对局。

## 验收标准

- [ ] 交付附带运行环境、构建页面和全部运行依赖的目录，无需安装开发工具；启动显示可用局域网地址。
- [ ] 程序与数据分离，替换程序版本后保留已有房间、身份与对局数据，并验证恢复流程。
- [ ] 在 Windows 实际验证启动，由同一局域网另一台设备访问；不能用 macOS 结果代替 Windows 验收。
- [ ] 阻断互联网并清除浏览器缓存后，可加载页面、帮助、资源和电脑策略，完成对局；不请求 CDN 或在线模型。
- [ ] 记录使用步骤及实际验证证据；如缺 Windows 执行环境，明确留待实测，不报告通过。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T01、T02、T20 的交付验证。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
