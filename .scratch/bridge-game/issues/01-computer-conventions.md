# 01：明确电脑叫牌约定与基础牌力验收

Status: ready-for-agent

Blocked by: 无，可立即开始

**交付行为：** 形成电脑实现与中文帮助共用的叫牌约定，以及可独立评估基础做庄、防守行为的固定牌例。

## 验收标准

- [x] 在已选体系内明确五张高花、15～17 点 1NT、强 2♣、其余二阶花色弱开叫、基础应叫、Stayman、高花转移叫的适用条件。
- [x] 补齐再叫、竞争叫牌、干扰后的约定处理、规则优先级和未覆盖情形的合法退路；每项规则有标识和示例牌例，避免同一输入产生冲突叫品。
- [x] 拟定基础首攻、做庄、明手控制和防守的评估牌例、允许结果与通过条件，独立于后续实现；明确规则正确与牌力的区别。
- [x] 叫牌规则表提交用户确认，确认结论与评估标准记录在独立交付文档中；不能将草案当作已确认依据，不修改父规格。
- [x] 本票交付决策文档，不实现策略，不承诺普通牌友水平；后续电脑任务必须引用确认后的版本。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T13、T14；补齐规格 Further Notes 中两项前置条件。
