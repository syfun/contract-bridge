# 12：全员离线、房主转交与服务重启恢复

Status: ready-for-agent

Blocked by: 11：掉线等待、电脑接管与重连取回控制

**交付行为：** 无人在线时牌局停下并保存，玩家回归或服务重启后能恢复到已确认的位置。

## 验收标准

- [x] 单机关闭页面或最后真人离线被检测后立即暂停保存，优先于普通接管，不让电脑打完或自动开下一副。
- [x] 房主离线满 30 秒后转交给最早加入且在线的真人；全员离线后从已重连真人中按相同规则接任，转交不自动恢复。
- [x] 服务重启恢复叫牌、打牌和结算阶段的状态、身份、准备状态、累计分及操作去重信息，并保持暂停待房主确认。
- [x] 已有离线截止时间跨重启保留；无离线记录的连接从启动检测未连接时计时，不重置已有等待期。
- [x] 真实临时 SQLite 与可控时钟验证恢复；注入存储失败、提交后确认丢失和重试，不丢失已确认操作，不重复计分或推进。
- [x] 恢复快照按身份过滤，完整存档不得暴露给无权查看的客户端。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T18、T19、T20、T21，恢复场景的 T12、T15。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
