# 05：从首攻打完十三墩

Status: ready-for-agent

Blocked by: 04：完成真人叫牌并确定定约

**交付行为：** 真人从首攻连续打完一副牌，庄家操作明手并查看公开出牌记录。

## 验收标准

- [ ] 首攻后在正确时点公开明手；仅庄家当前控制者能替明手出牌，其他手牌保持私有。
- [ ] 强制跟牌，正确处理将牌、无将、赢墩与下一墩首家，十三墩结束后进入待结算阶段。
- [ ] 展示合法牌、选牌与再次确认出牌、当前墩及完整公开记录；手机上可读取和操作本人及明手手牌。
- [ ] 拒绝越权、越轮次、重复牌和过期操作；每次合法出牌事务提交后确认。
- [ ] 通过公开入口完成固定牌副，覆盖明手授权和各种赢墩边界，不用内部函数调用次数作为验收。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T08、T09、T12、T15、T21、T23 的出牌部分。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
