# 04：完成真人叫牌并确定定约

Status: ready-for-agent

Blocked by: 03：房主开局、发牌与私有手牌展示

**交付行为：** 真人在牌桌上完成合法叫牌，查看记录并进入全体不叫结束或定约成立后的阶段。

## 验收标准

- [x] 支持 Pass、1～7 阶定约叫品、加倍与再加倍，校验轮次、级别、阵营和合法条件，并显示合法操作提示。
- [x] 正确处理开局四家不叫，以及有效叫品后的连续不叫结束；正确确定定约、加倍状态、庄家和首攻方。
- [x] 各身份可查看完整公开叫牌记录及当前行动方；正常轮次不设置强制倒计时。
- [x] 叫牌与状态在同一事务提交，重复操作不重复叫牌，非法或过期操作不改变状态，客户端能读取最新授权状态。
- [x] 使用独立牌例覆盖叫牌边界和庄家认定；本票不实现电脑策略或结算界面。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T06、T07、T08 的庄家与首攻方部分、T15、T21。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
