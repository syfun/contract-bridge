# 11：掉线等待、电脑接管与重连取回控制

Status: ready-for-agent

Blocked by: 09：电脑做庄、防守，完成单机与人数不足的对局；10：房主暂停与恢复整桌

**交付行为：** 短暂断网可等待重连，长时间断网由电脑补位，原玩家回归后继续自己的座位。

## 验收标准

- [x] 检测掉线后等待 30 秒，未到期不接管，轮到掉线座位时等待；其他合法操作可继续。
- [x] 到期后电脑接管且保留原玩家座位；原玩家重连在下一次该座位操作前取回控制，已提交动作不撤回。
- [x] 区分持久座位归属、连接状态与实际控制者，禁止新玩家抢占；接管座位在两副之间自动准备。
- [x] 思考期间暂停、重连或状态变化使旧结果失效，随后有效操作能正常推进。
- [x] 可控时钟覆盖截止前后边界，浏览器展示断线、等待、接管及恢复状态；更新持久离线截止时间。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T11 的接管准备部分、T16、T17、T23 的重连部分。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
