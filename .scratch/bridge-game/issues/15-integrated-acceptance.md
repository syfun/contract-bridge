# 15：完成多桌与跨浏览器交付验收

Status: ready-for-agent

Blocked by: 14：交付 Windows 离线启动包

**交付行为：** 交付经过多桌并发、桌面与手机完整流程验证的基础版，并提供可复核结果。

## 验收标准

- [ ] 10 桌含电脑决策并发运行，无跨房间串牌、牌局停滞或操作丢失，记录环境、耗时、资源占用及发现的问题，不新增硬件或延迟阈值。
- [ ] 多个独立浏览器身份覆盖 1～4 真人入房至结算、准备、重连与换人，在桌面和手机视口检查全部关键操作。
- [ ] 根据参考稿检查信息层级、选牌反馈、合法操作提示、明手、记录、结算及暂停状态，修复遮挡、误触和状态不一致。
- [ ] 汇总 T01～T23 的证据、执行平台、结果和剩余限制；修复本票发现的集成缺陷并回归对应场景。
- [ ] 单独报告规则与流程正确、基础策略牌例结果，不将稳定完局等同普通牌友水平。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T01～T23 集成回归，重点 T22、T23。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
