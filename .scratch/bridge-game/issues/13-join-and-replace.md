# 13：中途加入、退出与两副之间换人

Status: ready-for-agent

Blocked by: 11：掉线等待、电脑接管与重连取回控制

**交付行为：** 新玩家可等待接替可用电脑座位，原玩家和房主可按权限释放座位而保留本桌成绩。

## 验收标准

- [x] 当前副中新加入者进入等待界面，不看到暗牌也不能接替电脑；下一副只可接替无人归属的可用座位。
- [x] 原玩家可主动退出并释放归属；当前副如需补位由电脑继续，新真人仍需等下一副接替。
- [x] 房主仅在两副之间可释放离线玩家座位，其他玩家无权释放；单纯电脑接管不释放原归属。
- [x] 退出涉及房主或最后真人时遵循已有房主转交与全员离线暂停规则；与恢复任务联验相关组合。
- [x] 换人、重新准备及进入下一副不清空累计分，竞争选座只有一个成功，旧凭据不能继续操作已释放座位。

## 依据与实施约束

- [正式规格](../spec.md)。验收覆盖：T04、T05、T11、T12、T16 的归属部分。
- 使用项目领域术语与已确认架构；每项涉及的操作都需服务端授权、按房间顺序处理、版本与重复操作校验，并在持久化成功后确认和广播。
- 以对局应用服务公开行为为主要测试入口，按需使用可控发牌、时钟和真实临时 SQLite；关键浏览器流程随本票验证。
- 界面参考用户提供的 [Open Design 参考稿](../../../design/references_classic.html)：以柔和绿牌桌、清晰座位方位、手牌与侧栏布局为视觉依据，保留清楚的操作反馈、可读字号和触控尺寸。参考稿未覆盖的房间、联机与恢复状态沿用同一视觉风格。
- 参考稿是视觉与交互依据；其中电脑固定不叫、简化计分及页面内模拟状态不作为业务实现依据。按正式规格补齐加倍、再加倍、身份隔离、持久化和恢复；主题切换不新增为必做范围。
- 本票可在第 12 票完成前实现换人主体行为；涉及房主转交与全员离线恢复的组合在第 14 票前与第 12 票联验。
