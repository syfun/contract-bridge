## 共同定义与唯一选择

- 只算大牌点 HCP：A=4、K=3、Q=2、J=1，其余为 0；第一版不加长度点、短套点，不按局况或座次调整阈值。
- 手牌记作 `♠/♥/♦/♣`，T 表示 10，空门为 `-`。牌型顺序同上。均型只包括任意排列的 4333、4432、5332；“无五张高花”是单独限制。
- 高花为 ♥、♠，低花为 ♣、♦。定约叫品从低到高为 ♣、♦、♥、♠、NT，再升阶。新花色指己方尚未自然叫过的花色，敌花指对方叫过的花色；不猜测真人的人工叫品，保守按所叫花色处理。
- 选最长套时，同长依次选 ♠、♥、♦、♣；特别规则优先：两个四张高花的一阶应叫先 ♥；低花开叫 3–3 先 ♣，4–4 先 ♦。
- “最低叫”指高于当前最高定约的该花色最低合法叫品；“跳一阶”是在最低叫上增加一阶。“止张”至少有 A、Kx、Qxx、Jxxx 中一种。长度包含该大牌本身。
- “支持”按本手真实长度与搭档公开承诺的长度相加判断；不得读取搭档实际手牌。以下涉及支持的规则另写具体张数，不从真人的未定义叫品推导承诺。
- 表中序列省略对手的 Pass，己方叫品依次列出；括号内是对手的非 Pass 叫品。问号是当前行动，未括起的最后一个已有叫品属于搭档。示例用下方手牌字母指定当前电脑的完整手牌；示例只给当前电脑信息，不暗含另三家的真实手牌。
- 邀请叫不逼叫；止叫允许搭档 Pass。自然新花色应叫和本文明确写明的人工问叫只逼叫一轮；未写“逼叫”的规则均不逼叫。逼叫是策略约定，Pass 在桥牌规则上仍可能合法。

| 优先级 | 标识 | 处理及示例 |
| --- | --- | --- |
| 1 | G01 | 无当前行动权、暂停、状态过期或合法动作集合为空时不返回可提交动作；例如暂停期间手牌 A 不叫 1NT。服务端仍需复验。 |
| 2 | G02 | 对手在己方首次非 Pass 叫品之后作任何非 Pass 叫品（含加倍、再加倍），永久取消本副己方未完成的人工约定、邀请和逼叫义务，进入 C06/C07；例 `1NT–(X)`，F 不再叫 Stayman。对手只有 Pass 不取消。 |
| 3 | G03 | 无干扰时，按可识别的叫牌历史选择唯一专用阶段：NT 后续 N、强开叫 S、弱开叫 W、一阶花色首次应叫 R、开叫人首次再叫 B、应叫人后续 F。阶段不跨套套用；例 `1NT–2♦; ?`，A 用 N03，不把 2♦ 当自然应叫。 |
| 4 | G04 | 己方尚未非 Pass、对方也未非 Pass 时用 O；己方尚未非 Pass、对方已叫定约时用 C01～C03；搭档首次技术性加倍且此后对手只 Pass 时用 C04；搭档首次自然争叫后的首次应叫用 C05。各表从上到下取首个满足条件且输出合法的规则。例 B 同时均型且五张 ♠，用 O04。 |
| 5 | G05 | 未识别历史或无表项命中：无逼叫义务则 Pass；有一轮义务则先最低合法叫自己的最长至少四张套（最高三阶），再 2NT，再 3NT，仍无合法候选则 Pass 并记录“逼叫无法安全续叫”。例 `1♣–1♠–4NT; ?`，K 用 Pass，不把 4NT 当问 A；例 `1♣–1♠; ?`，S 的 2♥ 逆叫不满足点力，用最长套退路 2♣。 |

同一阶段只生成一项最终建议，同时记录规则标识、输入版本和可见依据。候选非法时跳过该候选/表项，最后 G05；不能把非法叫品机械抬高到另一阶而保留原含义。G05 逼叫退路与 C07 不承诺新的点力或牌型，中文帮助必须说明。所有表格中的“最高”均是硬上限。

## 叫牌规则

### 开叫 O

适用：己方和对方此前均只 Pass，四个座次相同。

| 标识 | 适用条件与唯一叫品 | 示例牌例 |
| --- | --- | --- |
| O01 | HCP≥22：2♣，人工强牌，逼叫一轮；不使用赢墩估值替代点力门槛 | C → 2♣；T → 2♣ |
| O02 | 20～21 HCP、均型且无五张高花：2NT；本版本不接 Stayman/转移 | Z → 2NT |
| O03 | 15～17 HCP、均型且无五张高花：1NT | A → 1NT；B 不命中 |
| O04 | 12～21 HCP：有至少五张高花，开最长高花；否则开最长低花，3–3 选 ♣、4–4 选 ♦ | B → 1♠；E → 1♣；Y → 1♦ |
| O05 | 6～10 HCP：有恰好六张的 ♦/♥/♠，该套含 A/K/Q 中至少两张，且无另一门四张以上高花：开该套二阶；多套满足取最长套同长顺序 | D → 2♥；Q → 2♠；V → 2♦；L → 2♠ |
| O06 | 其余 Pass；不作三阶阻击或轻开叫；11 HCP 也 Pass | K → Pass；H → Pass（高花仅五张） |

### 一阶花色开叫的首次应叫 R

适用：搭档 O04 型自然开叫，轮到本方首次应叫，无对手干扰。按顺序首项命中；R02/R04 的自然新花色逼叫一轮，不使用“二盖一逼局”。

| 标识 | 适用条件与唯一叫品 | 示例牌例 |
| --- | --- | --- |
| R01 | 搭档开高花，本手支持≥3 张且≥6 HCP：6～9 叫二阶、10～12 叫三阶邀请、≥13 叫四阶止叫 | `1♠; ?`，F → 2♠，I → 3♠，J → 4♠ |
| R02 | ≥6 HCP，有可在一阶叫出的至少四张新花色：选最长，两个四张高花先 ♥，其余同长按共同定义 | `1♣; ?`，G → 1♥；H → 1♠ |
| R03 | 无前项，搭档开低花、均型且≥10 HCP：10～12 叫 2NT 邀请，≥13 叫 3NT 止叫 | `1♦; ?`，O → 3NT；E 不命中，R02 已优先叫 1♥ |
| R04 | ≥10 HCP，有可在二阶最低叫的至少四张新花色；`1♠–2♥` 须五张 ♥；选最长，同长按共同定义 | `1♠; ?`，AA → 2♣；S 不命中，R01 已优先叫 4♠ |
| R05 | 搭档开低花、支持≥5 张且≥6 HCP：6～9 二阶、10～12 三阶、≥13 五阶止叫 | `1♣; ?`，W → 2♣ |
| R06 | ≥6 HCP：1NT，不逼叫，可为非均型；更高点力但未命中前项也保守使用本项，不暗示只有 6～9 | `1♠; ?`，AB → 1NT |
| R07 | <6 HCP：Pass | `1♥; ?`，K → Pass |

R03 的 NT 不要求无叫过花色以外的止张（无竞争）。本版本不用直接跳新花强应叫、Jacoby 2NT、低花反加叫，故 R03 的 2NT 为自然邀请。表内反例用于解释优先级，正例才是该规则的验收输入。

### 一阶开叫人的首次再叫 B

适用：开叫人使用 O04，搭档使用 R，自然新花色应叫的逼叫义务在本次叫品后消耗。按以下顺序。

| 标识 | 适用条件与唯一叫品 | 示例牌例 |
| --- | --- | --- |
| B01 | 搭档已叫 3NT、4♥、4♠ 或 5♣/5♦：Pass；不自动探满贯 | `1♠–4♠; ?`，B → Pass |
| B02 | 搭档加叫本门高花至二阶：12～15 Pass，16～18 三阶邀请，19～21 四阶；加叫至三阶：12～14 Pass，15～21 四阶 | `1♠–2♠; ?`，B → 3♠；`1♠–3♠; ?`，B → 4♠ |
| B03 | 搭档加叫本门低花至二/三阶：12～18 Pass；19～21 均型叫 3NT，否则 Pass。搭档自然 2NT 邀请：12～14 Pass，15～21 叫 3NT | `1♦–2♦; ?`，Y → 3NT；`1♣–2NT; ?`，E → Pass |
| B04 | 搭档自然叫新高花，本手≥4 张支持：12～15 最低加叫至二阶，16～18 三阶，19～21 四阶 | `1♣–1♥; ?`，E → 2♥ |
| B05 | 搭档自然新花色，本手均型：12～14 最低合法 NT（最高 2NT），15～19 叫 2NT，20～21 叫 3NT | `1♦–1♠; ?`，Y → 2NT；`1♣–1♠; ?`，E → 1NT |
| B06 | 自身开叫套≥6 张：12～15 最低再叫（最高三阶），16～18 跳一阶再叫（最高三阶），19～21 高花叫四阶、低花叫五阶 | `1♠–1NT; ?`，M → 3♠；N → 4♠ |
| B07 | 有另一至少四张套，可最低叫在二阶内，且非逆叫或 HCP≥17：叫该套，多个候选取最长/同长顺序；逆叫指新套比开叫套高级且叫到二阶 | `1♣–1♠; ?`，S 不允许 2♥ 逆叫（15 HCP），落 G05 → 2♣；正例 AC → 2♥ |
| B08 | 搭档叫 1NT 且无前项：12～15 Pass，16～18 叫 2NT，19～21 叫 3NT；否则 G05 | `1♠–1NT; ?`，B → 2NT |

这里 B05 的 2NT 明示宽范围 15～19，是第一版简化；不会被中文帮助误写成标准的 18～19。已识别序列必须保留开叫人角色，不能再次当作新开叫。

### 应叫人后续 F

仅处理以下紧接 B 的序列；后续未列出的往返进入 G05，不重复发起邀请。

| 标识 | 适用条件与唯一叫品 | 示例牌例 |
| --- | --- | --- |
| F01 | 已确认八张高花配合、搭档停在二/三阶：合计下限≥25 叫四阶，否则 Pass。下限取搭档最后一项自然规则的最小 HCP，加本手 HCP | `1♣–1♥–2♥; ?`，G（13+12）→ 4♥；F → Pass |
| F02 | 搭档 B05/B08 再叫 1NT/2NT：合计下限≥25 叫 3NT，否则 Pass；不在无将再叫后重新启动 Stayman/转移 | `1♣–1♠–1NT; ?`，J（14+12）→ 3NT；H → Pass |
| F03 | 搭档 B06 再叫自己的高花，本手≥2 张支持且合计下限≥25：叫四阶；否则 Pass | `1♠–1NT–3♠; ?`，AE（9+16）→ 4♠；K → Pass |
| F04 | 搭档 B07 再叫新高花，本手≥4 张支持且合计下限≥25：叫四阶；否则 Pass | `1♣–1♠–2♥; ?`，AG（13+17）→ 4♥ |
| F05 | 其余 G05，未承诺逼局；不探索满贯 | `1♦–2♣–3♦; ?`，W → Pass |

“合计下限”只能来自已识别规则。真人序列若可归入某表项，使用该表项公开下限；若不可识别，进入 G05，不能根据其实际手牌猜规则。

### 无将体系 N

N01～N09 只用于无干扰的 1NT 开叫及其指定后续。有五张高花先转移，不同时用 Stayman。

| 标识 | 适用条件与唯一叫品 | 示例牌例 |
| --- | --- | --- |
| N01 | 应叫人有≥5 张高花，不限点力：最长高花，5–5 先 ♠，♥ 用 2♦ 转移、♠ 用 2♥ 转移；逼叫一轮 | `1NT; ?`，H/I/J → 2♥；D → 2♦ |
| N02 | 无五张高花，≥8 HCP 且有四张高花：2♣ Stayman，逼叫一轮 | `1NT; ?`，F/G → 2♣ |
| N03 | 开叫人收到转移：最低完成到 2♥/2♠，不超级接受 | `1NT–2♦; ?`，A → 2♥ |
| N04 | 开叫人收到 Stayman：有四张 ♥ 叫 2♥（两门四张也先 ♥），否则四张 ♠ 叫 2♠，否则 2♦ | `1NT–2♣; ?`，R → 2♥；A → 2♦ |
| N05 | 转移完成后应叫人：0～7 Pass；8～9，五张目标高花叫 2NT、六张以上叫 3 高花邀请；≥10，五张叫 3NT、六张以上叫 4 高花 | `1NT–2♥–2♠; ?`，H → Pass；I/J → 3NT；L → 4♠ |
| N06 | Stayman 回答后应叫人：若回答高花与自身四张配合，8～9 叫 3 高花、≥10 叫 4 高花；否则 8～9 叫 2NT、≥10 叫 3NT | `1NT–2♣–2♥; ?`，F → 3♥，G → 4♥；`…–2♦; ?`，G → 3NT |
| N07 | 开叫人面对 N05 的 2NT/3 高花邀请：15～16 拒绝、17 接受；目标高花合计≥8 张（2NT 承诺五张、3 高花承诺六张），拒绝最低叫 3 高花或 Pass 已有 3 高花，接受叫 4 高花；合计<8，拒绝 Pass 2NT/3 高花，接受叫 3NT。面对 N05 的 3NT，支持≥3 改为 4 高花，否则 Pass | `1NT–2♥–2♠–3NT; ?`，A → 4♠ |
| N08 | 开叫人面对 N06 的 3 高花或 2NT 邀请：15～16 Pass，17 分别叫 4 高花或 3NT；应叫人下一轮 Pass。N06 叫局后开叫人 Pass | `1NT–2♣–2♥–3♥; ?`，R → Pass |
| N09 | 1NT 首次应叫无前项：0～7 Pass、8～9 叫 2NT、≥10 叫 3NT；开叫人对该 2NT，15～16 Pass、17 叫 3NT；其他结束叫品后 Pass | `1NT; ?`，K → Pass，W → 2NT，O → 3NT |
| N10 | O02 的 2NT：应叫人 0～4 Pass、≥5 叫 3NT；其后 Pass，无人工应叫，无转移 | `2NT; ?`，K → Pass，H → 3NT |

简化边界：Stayman 回答 2♥ 后，应叫人只有四张 ♠ 而无四张 ♥ 时按 N06 叫无将；不继续查询另一高花，可能漏掉 4–4 ♠ 配合。接受这个限制与宽范围无将再叫，是本次确认的一部分。全部直接 4NT 均不解释为问 A；不使用 Gerber、Blackwood、Texas 转移。

### 竞争叫牌与干扰 C

C01～C03 只在己方此前均 Pass、对方恰有一次自然花色开叫且最高不超过 2♠ 时适用（其他敌方叫品可为 Pass）。不区分直接争叫和第四家平衡位置；不因局况降低门槛。

| 标识 | 适用条件与唯一叫品 | 示例牌例 |
| --- | --- | --- |
| C01 | 15～18 HCP、均型、有敌花止张，且 1NT 合法：争叫 1NT；优先于技术性加倍，不接人工约定 | `(1♥); ?`，A → 1NT |
